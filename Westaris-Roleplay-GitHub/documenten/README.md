## Belangrijke informatie

Deze documenten zijn bedoeld voor de roleplay-server. Het gaat niet om authentieke Amerikaanse of Nederlandse wetgeving. De strafklassen, tarieven en zones moeten vóór toepassing door het serverbestuur worden goedgekeurd.

Wijzig je een wet, werk dan zowel het Markdown-document **als** de bijbehorende webpagina en de zoekindex (`assets/search-data.js`) bij. Er is nog geen automatische synchronisatie tussen beide versies.
